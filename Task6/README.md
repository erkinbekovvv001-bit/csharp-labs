## Сұрақтарға жауап

**1. text[i] нені қайтарады, типі қандай? Неге text[i] = 'a' деп жазуға болмайды?**

text[i] жолдың i индексіндегі символды қайтарады. Оның типі char. String өзгермейтін тип болғандықтан, жеке символын тікелей өзгертуге болмайды.

**2. Қазақ әріптері дұрыс өңделді ме?**

char.IsUpper әдісі символдың бас әріп екенін тексереді, ал char.ToLower оны кіші әріпке ауыстырады. Қазақ әріптерін де жеке тексеруге болады.

**3. result += ch орындалғанда жаңа жол жасала ма?**

Иә, жаңа жол жасалады. Себебі string өзгермейтін тип, бастапқы жол өзгеріссіз қалады.

## Git сұрақтары

**1. task5 тармағындағы коммиттер main-ге қалай түсті?**

Pull Request арқылы main тармағына біріктірілді. Біріктірілгеннен кейін task5 тармағы сақталды.

**2. commit пен push айырмашылығы неде?**

Commit өзгерістерді жергілікті репозиторийге сақтайды. Push өзгерістерді GitHub-қа жібереді.

**3. .gitignore не үшін керек?**

.gitignore қажетсіз файлдарды Git-ке қоспау үшін қолданылады. bin/ және obj/ папкалары бағдарлама құрастырылған кезде автоматты түрде жасалады.
